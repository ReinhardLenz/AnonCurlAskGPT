# AnonCurlAskGPT
A web page, where a user can anonymously ask a question "ask me anything". Then the web page php  transmit this via method POST form to another page , a promt variable is created with this input, sent to chatGPTand the answer to the question is posted. A txt or xlsx file can be added.
Requirement: 
in the same directory, where these 2 files are installed, in the terminal you must run :composer require phpoffice/phpspreadsheet. This command will generate a vendor subdirectory in the same directory.

Also, a "uploads" directory must be created in the same directory level
